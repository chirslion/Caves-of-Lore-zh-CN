Caves of Lore 汉化 · 游戏术语说明
================================================

本文件解释汉化中一些容易被误解的词条，尤其是物品详情里的
「附魔 / 学派加成」。这些词条来自原版游戏的属性名，不是汉化
新增的数值；下面按游戏代码说明它们的实际作用。

一、物品详情里的学派加成
------------------------
物品详情中的「毁灭魔法 / 束缚魔法 / 防护魔法 / 召唤魔法 / 位移魔法 /
转化魔法 / 转移魔法」是原版七大学派的法术加成词条。词条后面的
数字按学派不同，作用也不同：

· 伤害（Damage）
  毁灭系：直接增加该学派法术造成的伤害。

· 效果（Effects）
  指“法术效果强度 / 效力”，不是“效果个数”。
  具体加到哪里由各法术自己的公式决定，例如：
    防护系：护盾 / 治疗 / 圣光的效果量
    位移系：位移距离、墙壁持续时间
    束缚 / 转移系：控制、吸取类效果的效果量与持续时间
  所以不必把它理解成“多一个效果”。

· 记忆（Memorize）
  指“法术记忆进度”。游戏里反复施放同一法术会积累记忆进度，
  进度满 100% 后永久记住该法术（提示“已记忆”）。
  束缚 / 位移 / 转化 / 转移系的装备加成，会让对应学派的法术每次
  施放额外增加约 1% 的记忆进度（+1 = 每次 +1%）。

· 全部记忆（Memorize All）
  原版转化魔法词条的写法。按代码，它同样是“施放转化系法术时
  增加记忆进度”，并不是让所有学派法术一起加速；这里保留原版
  词条的直译，实际效果以上面的“记忆”说明为准。

· 法术持续时间（Spell Duration）
  延长转化系法术产生的效果持续时间。

· 怪物生命加成（Monster Health Bonus）
  召唤系：提高召唤物的生命 / 法力（并影响召唤数量）。

二、物品面板其他词条
--------------------
· 材质：物品的材质类别（木头 / 铁 / 银 / 刚玉 / 布料 / 皮革等）。
· 套装：物品所属套装；集齐同套装部件会获得套装加成。
· 独特：独一无二的物品（通常不能重复获得）。
· 附魔：物品上的附魔效果，通常可以剥离 / 更换（视物品而定）。
· 价格：商店买卖价格（受议价技能影响）。

三、品质前缀与属性词缀
----------------------
装备名可能由「品质前缀 + 基名 + 属性词」组成，例如：
  卓越毛皮长靴
  长弓·污染
· 品质前缀：精良 / 磨砺 / 精致 / 卓越（由低到高）。
· 「·」后的属性词：装备生成时附加的属性（如 污染、滋扰、荒野），
  不同属性词对应不同学派 / 属性加成；它不是人名分隔符。

四、其他常见提示
----------------
· 「对抗 木质」「对抗 飞行」：对特定敌人类型（躯体类型或生物类别）
  的伤害加成，不是对某种武器 / 材质。
· 「距离 1 时伤害减半」：长鞭 / 长矛 / 连枷等“长兵（Reach）”武器
  贴身攻击时伤害减半；隔一格攻击正常。
· 「需要一把刚玉镐」：该矿点需要对应材质的镐才能开采。
· 按键设置里的键名、部分队伍人名 / 谜题答案保留英文：这些是
  游戏匹配机制使用的标识，翻译后会导致按键或谜题失效。

说明：以上为基于游戏代码的机制解释；原版提示文字有时比较简略，
实际效果以代码行为为准。若发现译文与实机效果不符，请附截图反馈。
